# テスト仕様書

人事DX 入社手続き自動化ポートフォリオで、各段階に行ったテストと、その結果をまとめた記録です。

本書は、開発中の作業記録、Google 上の実機テスト、ローカル模擬テストの結果をもとに整理しています。現時点で実施していないテストは、「9. 未実施の一覧」に書いています。

## 1. テストの方針

- **段階ごとにテストし、合格してから次の段階へ進みました。** 合格の判断は、開発者本人が Google の実際の画面で結果を見て行いました。
- **テストデータは、すべて架空の人物です。** 実在の人物の氏名・住所・電話番号・メールアドレスは使っていません。
- **メールはテストモードで確認しました。** テスト中のメールは、テスト用の送り先1か所にだけ届きます。本番の送り先には送っていません。
- テストは2種類あります。

| 種類 | 中身 |
|---|---|
| **実機テスト** | Google Apps Script を Google 上で実際に動かし、フォーム・スプレッドシート・ドキュメント・メールの結果を画面で確かめるテスト |
| **ローカルテスト** | Google の部品（シートや文書など）を手元のパソコンで真似した「模擬」を作り、コードの判断が正しいかを確かめるテスト。Google のデータには触れない |

### 判定の書き方

| 判定 | 意味 |
|---|---|
| 合格 | 期待どおりの結果になった |
| 修正後合格 | 最初は不具合が出たが、直したあとの再テストで期待どおりになった |
| 未実施 | まだテストしていない |

「記録日」は、テストの結果が開発の記録に書かれた日です（日本時間）。
